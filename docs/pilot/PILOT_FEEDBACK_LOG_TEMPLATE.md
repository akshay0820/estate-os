# Pilot Feedback and Issue Log (template)

Keep this as a shared spreadsheet with exactly these columns. The app has no feedback feature. One row per report.

| Column | Content |
|---|---|
| ID | FB-001, FB-002, … |
| Date | Reported (agency time zone) |
| Reported by (role) | |
| Affected workflow | Intake / qualification / matching / follow-up / appointment / CRM & data / reports / access / other |
| Observed behaviour | What happened |
| Expected behaviour | What should have happened |
| Business impact | Who or what was affected; how many leads |
| Severity | SEV-1…4 (handbook §12) |
| Category | Bug / reliability / data quality / usability / missing integration / training or onboarding / feature request / commercial or pricing |
| Reproduction steps | |
| Evidence | Lead or record ids (no personal data in the sheet), screenshots, Logs request id |
| Workaround | |
| Proposed fix | |
| Priority | From handbook §18 |
| Verification status | Open / fixed on staging / verified in pilot / won't fix (reason) |
| Closed date | |
